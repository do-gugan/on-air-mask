# 配信マスク / On-Air Mask

ブラウザの画面を映す配信や収録で、個人情報など見せたくない部分を、クリックで選んでぼかす Chrome / Edge 拡張機能です。

## こんな場面で

- **画面を見せながら解説する配信**：EC サイトや業務システムの管理画面を見せるときに、注文者名、住所、メールアドレスを隠す
- **Web サービスの解説動画・チュートリアル**：ログイン中のアカウント名、通知、閲覧履歴、おすすめ欄を隠す
- **ユーザーテスト・ユーザビリティテスト**：画面録画やライブ観察で、参加者のアカウント情報や、画面に出る個人データを隠す
- **社内デモやオンライン会議での画面共有**

## 配信マスクの強み

### 1. 「その要素」ではなく「ルール」で隠すので、外れにくい

クリックした要素そのものを覚えておく方式では、サイトが画面を描き直したり、スクロールで行が追加されたりすると、覚えた要素が作り直されてマスクが外れてしまいます。

配信マスクは、クリックした要素から「`.customer-name` に当たる要素はすべてぼかす」といった **CSS のルール**を作り、ページに置きます。ルールを当てるのはブラウザ自身なので、次のような場面でもマスクが自動で効き続けます。

- 無限スクロールで後から読み込まれた行
- 検索や並べ替えで描き直された一覧表
- SPA（ページ全体を読み込み直さないサイト）での画面遷移

ルールの候補は、クリックした要素だけでなく、その親の段からも作ります。候補ごとに、次の情報を見ながら選べます。

- **件数**：「この1件だけ」に当たるのか、「一覧表の列全体（N件）」に当たるのか
- **安定度**：サイトの再描画や改修があっても効き続けやすいか。自動生成されたクラス名など、変わりやすい名前は候補から外しています
- **プレビュー**：候補をクリックするだけで、その候補で隠した結果が実際のページに表示されます

### 2. リロード直後の映り込みを防ぐ設計

配信中にページを再読み込みすると、マスクが効くまでのわずかな時間に、生の情報が一瞬映ってしまうことがあります。配信マスクは、次の仕組みでこれを防いでいます。

1. **先に隠しておく**：マスクを設定したサイトでだけ、ブラウザがページを描き始める前の段階で、ページ全体を透明にする CSS を差し込みます。
2. **ルールを当ててから見せる**：保存しておいたマスクのルールを読み込んで適用し終えた時点で、透明を解除してページを表示します。
3. **描かれる前に当てる**：マスクは CSS ルールなので、ページの要素が組み立てられた時点でもう効いています。文字の一部だけを隠すマスクは、ページの組み立てが終わって隠す範囲を計算できるまで、表示を待ちます。
4. **書き換えにも描画前に追従する**：ページの中身が書き換わったときの再計算は、ブラウザが画面を描き直す前に行います。
5. **リロードしても設定が消えない**：「保存」を OFF にしたマスクも、ブラウザのセッション用の領域に残るので、リロードやページ遷移で消えることはありません。

ただし、どのサイトでも確実に防げるとは限りません（[注意事項](#️-注意事項)を参照）。

### 3. 文字の一部だけを隠せる（日本語の住所・氏名向け）

「古田様」の「様」だけを残す、住所の都道府県だけを残す、といった指定ができます。都道府県は47都道府県名で照合し、判定できなかった部分は**全体を隠す**側に倒します。ページの HTML を書き換えない方式なので、サイトの動作を壊しません。

### 4. そのほか

- **マスクごとに見た目を設定できる**：ぼかしか塗りつぶしかを選び、強さや色をマスクごとに変えられます。
- **後処理が要らない**：動画編集でモザイクをかけなくても、配信そのものを隠した状態で映せます。
- **外部への通信なし・無料・オープンソース**：設定はすべてお使いのブラウザの中に保存されます。

## ⚠️ 注意事項

> [!WARNING]
> **この拡張機能は、情報の映り込みを完全に防ぐことを保証しません。** 本番の配信・収録の前に、必ず十分なテストを行い、自己責任でご利用ください。

- **サイトの作りによっては、うまく隠れないことがあります。** 逆に、隠すつもりのない部分まで隠れることもあります。
- **ページの書き換えや遅れて届く読み込みで、隠した情報が再び表示されることがあります。** サイト側の改修でページの構造が変わると、設定済みのマスクが効かなくなる場合もあります。
- **本番と同じ画面、同じ操作手順で事前にテストしてください。** スクロール、ページ遷移、リロード、検索や並べ替え、ウィンドウサイズの変更なども確認してください。
- **マスクを作る操作そのものも画面に映ります。** 要素の選択、マスクの編集、一覧からのハイライトは、どれも配信に映ります。マスクの準備は配信を始める前に済ませてください。
- **ぼかしが弱いと、文字の形から内容を推測できる場合があります。** 重要な情報には「塗りつぶし」をおすすめします。
- **ブラウザ本体の表示は隠せません。** タブのタイトル、アドレスバー、入力の自動補完、ブラウザやOSの通知、ブックマークバーなどが該当します。
- **念のため、ほかの手段も併用してください。** たとえば、配信ソフトの遅延設定や、録画を公開する前の見直しです。

本ソフトウェアは無保証です。本ソフトウェアの利用によって生じたいかなる損害についても、作者は責任を負いません。

## 動作環境

| ブラウザ | 対応 |
|---|---|
| Google Chrome 116 以降 | ✅ |
| Microsoft Edge 116 以降 | ✅ |
| その他の Chromium 系ブラウザ（Brave、Vivaldi など） | 未検証（サイドパネルへの対応状況によります） |
| Firefox、Safari | 非対応 |

Windows、macOS、Linux のいずれでも動作します。

画面の表示言語は日本語と英語に対応しています。ブラウザの表示言語に合わせて自動で切り替わり、それ以外の言語では英語で表示されます。

## インストール（手動）

現在、Chrome / Edge ウェブストアへの掲載準備中です。現時点では次の手順で手動インストールしてください。

1. [Releases](../../releases) から最新の `on-air-mask-<バージョン>.zip` をダウンロードして展開します。`on-air-mask-<バージョン>` というフォルダができます（`git clone` でも構いません）。
   - 展開したフォルダは、インストール後も削除・移動しないでください。ブラウザはこのフォルダから拡張機能を読み込み続けます。
2. 拡張機能の管理画面を開き、フォルダを読み込みます。
   - **Chrome**：アドレスバーに `chrome://extensions` と入力し、右上の「デベロッパー モード」を ON にします。「パッケージ化されていない拡張機能を読み込む」から、`manifest.json` が入っているフォルダを選びます。
   - **Edge**：アドレスバーに `edge://extensions` と入力し、左側のメニューで「開発者モード」を ON にします。「展開して読み込み」から同じフォルダを選びます。
3. ツールバーのパズルアイコンから「配信マスク」をピン留めしておくと便利です。
4. インストール前から開いていたタブは、一度再読み込みしてください。

### 更新するとき

1. 新しいバージョンのファイルで、フォルダの中身を上書きします。
2. 拡張機能の管理画面で、配信マスクの再読み込みボタン（↻）を押します。
3. 使用中のタブを再読み込みします。

保存済みの設定は、更新後もそのまま引き継がれます。

## 基本の使い方

### 1. 隠したい部分を選ぶ

1. ツールバーの配信マスクのアイコンをクリックして、サイドパネルを開きます。
2. 「要素を選択」を押し、ページ上の隠したい部分をクリックします。
   - 選択中のクリックはページ側に伝わらないので、リンクやボタンを押しても動作しません。
   - 選択をやめるときは Esc を押します。
3. 編集枠が開き、マスクのプレビューがすぐにページに表示されます。

### 2. 隠す範囲を決める

「範囲の候補」に、「クリック要素」「親 1」「親 2」…と段が並び、それぞれの段にマスク範囲の候補が表示されます。

- 候補をクリックするか ↑↓ キーで選ぶと、その候補で隠した場合の見た目がページにプレビューされます。マウスを乗せただけでは切り替わらないので、誤って別の候補を選ぶことはありません。
- ←→ キーで、親子の段を移動できます。

候補に付いているバッジの意味は次のとおりです。

| バッジ | 意味 |
|---|---|
| この1件 | ページ内でこの部分だけを隠す |
| N件 | 同じ種類の部分をすべて隠す（一覧表の列全体など） |
| 安定／普通／壊れやすい | ページの再描画やサイトの改修があっても効き続けやすいかの目安 |

たとえば、注文一覧の「お名前」の列全体を隠したいなら、件数が行数と一致する候補を選びます。特定の1か所だけなら「この1件」の候補を選びます。迷ったら「安定」の候補を選んでください。

### 3. 見た目を決めて適用する

| 項目 | 内容 |
|---|---|
| 名前 | 任意。一覧での表示名になります（例: 「ヘッダーのアカウント名」） |
| 方式 | **ぼかし**：強さと、要素の外側へのはみ出し量を調整します<br>**塗りつぶし**：グレー、親の背景色、ページの背景色、指定色から選びます |
| 範囲 | サイト全体か、このページのみか |
| 保存 | OFF：ブラウザを閉じるまで有効（リロードやページ遷移では消えません）<br>ON：ブラウザを再起動しても残ります |

「適用」で確定します。「やめる」（Esc）で破棄します。

### 4. マスクを管理する

サイドパネルの「このサイトのマスク」一覧で、次の操作ができます。

| 操作 | 動作 |
|---|---|
| マウスを乗せる | そのマスクがページ上のどこにあるかを枠で表示します |
| クリック | 編集枠を開きます。「選び直す」で隠す部分を指定し直せます |
| スイッチ | マスクを個別にオン／オフします（設定は残ります） |
| × | 削除します |
| すべてクリア | このサイトのマスクをすべて削除します |

ヘッダーのスイッチを使うと、すべてのサイトのマスクを一時停止できます。

CSS に詳しい方は、「セレクタを直接入力」から CSS セレクタを書いてマスクを作ることもできます。

## 応用：文字の一部だけを隠す

表のセルなど、要素の中の文字の一部を残して、残りを隠せます。

1. 編集枠の「対象」を「一部を残す」に切り替えます。
2. 「残す」で、残す部分の種類を選びます。
3. 表示される「N件中 M件で一致」の件数を確認して、適用します。

| 残す部分 | 例（■ が隠れる部分） |
|---|---|
| 都道府県（住所の先頭） | `〒150-0001 東京都渋谷区神宮前1-2-3` → 「東京都」以外（郵便番号を含む）を隠す |
| 敬称（末尾の 様・さん・殿・御中） | `古田様` → `■■様` |
| 先頭から N 文字 | 先頭から2文字なら `古田一義` → `古田■■` |
| 末尾から N 文字 | 末尾から4文字なら `090-1234-5678` → `■■■■■■■■■5678` |
| 正規表現に一致する部分 | `^.+?[市区町村]` なら、住所の市区町村までを残します |

- **判定できなかった部分は、全体を隠します。** 都道府県が書かれていない住所や、敬称の付いていない名前などが該当します。件数表示が「K件は判定できないため全体をマスク」となっていれば、その件数がこれにあたります。
- **都道府県の判定方法**：47都道府県名と、テキストの先頭（郵便番号と空白の直後）だけを照合します。住所の途中に出てくる「大阪府立〇〇」のような文字列には反応しません。
- **文字単位の「ぼかし」は「ぼかし風」の表示です。** 文字を透明にして、ぼかした影だけを描いています。確実に隠したい場合は「塗りつぶし」（文字幅の帯）をおすすめします。
- **入力欄の中の文字には使えません。** `<input>` などの入力欄の中の文字は文字単位で扱えないので、要素全体を隠します。

## データの取り扱いと権限

- この拡張機能は、**外部への通信を一切行いません。** 閲覧履歴や画面の内容を収集したり、送信したりすることもありません。
- マスクの設定は、お使いのブラウザの中だけに保存されます（`chrome.storage.session` と `chrome.storage.local`）。

| 権限 | 用途 |
|---|---|
| すべてのサイトへのアクセス（`<all_urls>`） | 任意のサイトでマスクを表示するため |
| `storage` | マスクの設定を保存するため |
| `sidePanel` | 操作用のサイドパネルを表示するため |
| `scripting` | マスクのあるサイトだけ、リロード時に生の情報が一瞬見えないようにするため |
| `tabs` | 表示中のタブとサイドパネルを連携させるため |

## 既知の制限

- 要素の選択、プレビュー、ハイライトは、ページ本体（トップフレーム）でのみ使えます。保存したマスク自体は iframe の中にも適用されますが、照合されるのはその iframe 自身のオリジンです。
- Shadow DOM の内部の要素は、個別に指定できません（外側のホスト要素ごと隠すことはできます）。
- canvas に描画しているアプリ（Google スプレッドシートの表の本体など）は、部分的に隠せません。
- ぼかしをかけた要素の中に `position: fixed` の要素があると、レイアウトが崩れることがあります。
- `chrome://` で始まるページや、拡張機能のストアのページでは動作しません。

## 開発者向け

```
manifest.json      拡張機能の定義（key で拡張機能 ID を固定）
background.js      service worker（リロード時の表示抑制の登録など）
content.js         マスクの適用、要素の選択、セレクタ候補の生成、文字単位のマスク
panel.html/js/css  サイドパネルの UI
guard.css          リロード時に、マスクの適用が終わるまでページを隠す CSS
_locales/          表示名と説明文（日本語と英語）
icons/             アイコン（PNG と元の SVG。16・32px は簡略版、128px はストア用に余白付き）
docs/DESIGN.md     設計メモ
docs/demo/         動作確認とスクリーンショット撮影用のデモページ（架空データ）
docs/store/        ストア申請用の説明文・画像・申請項目のメモ
PRIVACY.md         プライバシーポリシー
scripts/           配布用 zip の作成スクリプト（ストア提出用 build-store-zip.sh、Release 用 build-release-zip.sh）
```

ビルドは不要で、ファイルを編集して拡張機能を再読み込みすれば反映されます。

### 翻訳を追加する

表示する文言はすべて `_locales/<言語コード>/messages.json` にあります。新しい言語に対応させるには、このファイルを1つ追加するだけで、コードの変更は要りません。

1. `_locales/en/messages.json` を `_locales/<言語コード>/messages.json` にコピーします。言語コードは `ko`、`zh_CN`、`pt_BR` のように Chrome の形式で書きます（地域の区切りはアンダースコア）。
2. 各項目の `message` だけを翻訳します。キー名、`description`、`placeholders` はそのまま残し、`$N$` や `$TOTAL$` のような差し込み記号も消さないでください。`description` には、その文言が画面のどこで使われるかを書いてあります。
3. 拡張機能を再読み込みし、ブラウザの表示言語をその言語にして確認します。

翻訳していない項目は英語で表示されるので、途中までの翻訳でも画面は壊れません。翻訳のプルリクエストを歓迎します。内部の仕組みは [docs/DESIGN.md](docs/DESIGN.md) を参照してください。

## English summary

**On-Air Mask** is a Chrome / Edge extension for streamers, tutorial creators and usability researchers who share their browser screen. Click any element to blur or fill it. Instead of remembering the clicked element, it turns your pick into a CSS rule: you choose among candidate selectors with live previews, match counts and stability hints. The browser then keeps applying the rule to re-rendered and lazily loaded content. On reload, masked sites stay hidden until the rules are applied. The mask persists across scrolling, in-site navigation and reloads, and also applies to rows loaded later. The UI is available in English and Japanese (selected automatically from the browser language). You can also keep part of the text and hide the rest, such as keeping only the prefecture of an address or the honorific after a name. **It does not guarantee that nothing leaks. Test thoroughly before going live, and use it at your own risk.** No data ever leaves your browser.
