ブラウザの画面を映す配信や収録で、個人情報など見せたくない部分を、クリックで選んでぼかす拡張機能です。

■ こんな場面で
・EC サイトや業務システムの管理画面を見せながら解説する配信（注文者名、住所、メールアドレスを隠す）
・Web サービスの解説動画やチュートリアル（アカウント名、通知、閲覧履歴を隠す）
・ユーザーテストの画面録画やライブ観察（参加者のアカウント情報を隠す）
・社内デモやオンライン会議での画面共有

■ 特長
・「その要素」ではなく「ルール」で隠すので外れにくい
　クリックした要素から CSS のルールを作り、ページに置きます。無限スクロールで後から読み込まれた行や、検索・並べ替えで描き直された一覧表にも、自動でマスクが効き続けます。
・範囲を見ながら選べる
　クリックした要素とその親の段ごとに、マスク範囲の候補を並べます。「この1件だけ」か「一覧表の列全体」か、サイトの改修に強いかどうかを確かめ、実際のページでプレビューしながら選べます。
・リロード直後の映り込みを防ぐ設計
　マスクを設定したサイトでは、マスクを適用し終えるまでページを表示しません。リロードやページ遷移のあとも、マスクは維持されます。
・文字の一部だけを隠せる
　「古田様」の「様」だけを残す、住所の都道府県だけを残す、といった指定ができます。判定できなかった部分は、全体を隠す側に倒します。
・マスクごとに見た目を設定
　ぼかしか塗りつぶしかを選び、強さや色をマスクごとに変えられます。名前を付けたり、個別にオン／オフしたりもできます。

■ プライバシー
外部への通信は一切行いません。設定はすべてお使いのブラウザの中に保存されます。解析ツールや広告も含みません。ソースコードは GitHub で公開しています。

■ ご注意
この拡張機能は、情報の映り込みを完全に防ぐことを保証しません。サイトの作りによってはうまく隠れないことや、ページの書き換えで再び表示されることがあります。本番の配信・収録の前に、実際に使う画面と操作で十分にテストし、自己責任でご利用ください。タブのタイトルやアドレスバーなど、ブラウザ本体の表示は隠せません。
